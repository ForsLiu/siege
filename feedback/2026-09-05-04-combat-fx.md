Combat needs readable visual feedback, driven only by sim events (the renderer never touches sim state; replay hashes are identical with FX on or off).

1. Per-event effects: attack (melee swing arc or projectile trail + impact flash), spell cast (unit flash + short ability name toast), shield gained (shield segment on the hp bar + shimmer), heal (green pulse), lifesteal (green pulse on the attacker tied to the hit).
2. Floating numbers on every damage instance, coloured by damage kind, colours in data/ui/theme.json: physical, magic, true, and damage-over-time ticks as a fourth colour (smaller, no impact flash). Heals and lifesteal as green "+n". Font size scales with the amount: size = base + k·log10(1 + amount), clamped to a min and max; numbers on the same unit in the same tick are merged into one.
3. Numbers and effects are pooled objects; the fps overlay must not drop below the dev budget at 4× speed with 20 units per side. A dev toggle disables all FX.

[designer note] Damage kinds physical / magic / true already exist or are added to the effect vocabulary's damage(kind) parameter; "dot" is a delivery flag on damage events (periodic), not a fifth kind, so the sim stays unchanged when SPEC defines the real damage types.

## Acceptance
- Test: schema requires a theme colour for every damage kind and the dot flag.
- Test: replay hash unchanged with FX enabled vs disabled.
- Test: number merging (two hits, same unit, same tick → one number with the sum).
- Manual checklist: each of the five effect types visible in the sandbox with a fixture that triggers it.
