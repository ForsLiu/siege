Item system in the TFT shape, mechanism now, real item table from SPEC.md later (dev samples only, provisional).

Mechanism, all in data with the effect vocabulary:
- Components and completed items are item rows: id, name, kind (component | completed), stat mods, effects. A recipe table maps [componentA, componentB] → completed item (order-independent; two of the same component is a valid recipe).
- Each unit holds up to 3 items. Placing a component on a unit that already holds a component combines them immediately via the recipe table; a completed item occupies one slot.
- Item bench (inventory) UI; drag item onto unit = equipItem Command (validated: slot cap, target exists); no un-equip Command for now [designer note: TFT removes items via a consumable; leave a hook, do not add a dev-free remover yet].
- Selling a unit returns its items to the item bench. Merging three copies into a higher star moves items onto the resulting unit, up to the cap; the overflow returns to the bench.
- Items drop from encounters through data-defined loot tables rolled on the `loot` RNG stream (component drops, choice-of-N drops, completed item drops); the round-track reward preview shows them.
- Item effects run through the same hook bus as traits and abilities; stat mods from items are one modifier source per item.
