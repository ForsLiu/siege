The run screen must show the whole run at a glance. Mechanism only; augment and reward content are dev samples until SPEC.md defines them.

1. Round track (top bar): every round of the run in order with an icon per encounter type from data (normal, elite, boss, treasure/loot, augment round), the current round marked, past rounds dimmed. Hover a round = its reward preview (gold, xp, item drops, augment offer) as defined in the encounter data.
2. Gold panel: current gold, and a breakdown for the coming round computed by the sim, not the UI: base income, interest (with the rule shown, e.g. "1 per 10 gold, max 5"), win/loss streak bonus if the rules define one. The same breakdown appears in the round-end reward summary.
3. Shop: tier colours on cards, per-tier odds for the current level (from rules data) next to the level indicator, xp progress bar, reroll cost and buy-xp cost on their buttons.
4. Augments: chosen augments shown as icons with tooltips (name, effect text); augment rounds open a chooser of N options drawn from the `augment` RNG stream from data-defined offers; picking is a Command. Dev sample augments only.
5. Round-end summary before the next planning phase: result, damage taken (if defeated), rewards line by line, and the next round's encounter type.

## Acceptance
- Test: the sim exposes `incomePreview(state)` and it equals the gold actually granted at round end for 50 random-policy runs.
- Test: the round track derived from the encounter list is stable across a replay and matches encounter data order.
- Test: augment offers are deterministic per seed and the chosen augment's effects apply next combat.
