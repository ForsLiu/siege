Trait (class/origin) system, mechanism now, real traits from SPEC.md later (dev samples only, provisional).

Mechanism: a trait is a data row with id, name, description, and breakpoints [{count, effects[]}] using the effect vocabulary; `teamWide: true|false` decides whether the breakpoint effects apply to all allies or only holders. Active count = number of unique unit ids on the board that carry the trait (three copies or higher stars count once). Effects apply at combat start via the existing hook bus; an inactive trait applies nothing. Unit definitions list their traits.

UI: a panel on the run screen listing every trait on the board, sorted by active tier then count, each with icon/name, count vs breakpoints ("3 / 2 4 6" with the reached breakpoint highlighted), hover = effect text per breakpoint and the contributing units. Traits also appear in the unit inspector and on shop cards.
