## P0 — engine & tooling

- [ ] (P0-01) [infra] Effect vocabulary v1 — extend the interpreter to: damage(kind, amount, scaling by stat), heal, shield(amount, duration), statMod(stat, mul|flat, duration), stun(duration), applyTag(tag, duration), spawnProjectile(ref); triggers onCombatStart, onRoundStart, onAttack, onHit, onCast, onKill, onDeath, onTakeDamage, aura(range, effects); damage pipeline with ordered hooks (pre-mitigation → mitigation → post) and a per-fight damage ledger per unit. Dev sample units in data/dev exercise every effect. — acceptance: each effect has a fast test proving its numeric result; an unknown effect name fails schema validation; determinism suite green. — refs: infra
- [ ] (P0-02) [infra] Attack types & projectiles — melee vs ranged; deterministic tick-based projectile travel with speed from data; target shapes: single, hex radius r, line of n hexes, nearest-k; renderer events for spawn / travel / hit. — acceptance: a projectile hits on the predicted tick; radius and line selections tested on the hex grid; hashes identical with rendering off. — refs: infra
- [ ] (P0-03) [infra] Fight end rules — data-driven maxSeconds, overtime hook expressed as effects (e.g. all units lose x% max hp per second), draw resolution rule, FightResult with per-unit damage dealt / taken / healed, survivors, ticks, event count. — acceptance: mirrored boards draw at timeout; enabling the overtime effect ends the fight earlier; ledger totals equal the sum of hit events. — refs: infra
- [ ] (P0-04) [infra] Bot policy framework — policies are modules choosing from legalCommands(state); ship random (exists) and greedy (buy the strongest affordable, place strongest first, level when the data-defined economy rule says so, merge whenever possible); sweep runs any policy by name; policy interface documented in README. — acceptance: 20-seed sweep runs both policies with zero exceptions; greedy beats random on mean rounds survived over 50 seeds. — refs: infra
- [ ] (P0-05) [infra] Save/load — versioned JSON save of run state + seed + command log; migration registry; corrupt-save repair falls back to the last good round boundary; dev "export run" button. — acceptance: round-trip test; corrupt-file test; migration test with a bumped version. — refs: infra
- [ ] (P0-06) [infra] Replay viewer — dev screen loads seed + command log and plays it back at 1/2/4× through the renderer, checking the state hash at every round boundary; mismatch displayed. — acceptance: a random-policy run replays with every round hash matching; a tampered log is flagged. — refs: infra
- [ ] (P0-07) [infra] Tuner v0 — dev-only panel: every /data file listed; edit → zod validate → save through the dev endpoint → content reload (next run uses it); invalid edits rejected with the schema error; content hash shown. Production build has neither panel nor endpoint. — acceptance: edit→save→reload round-trip test via the endpoint; grep test proves dist/ contains no endpoint path. — refs: infra
- [ ] (P0-08) [infra] Codex v0 — read-only in-game browser generated from /data + schemas: every unit and encounter (later trait / item / augment) entry with its effects rendered as text. — acceptance: every data entry appears; snapshot test over dev content. — refs: infra
- [ ] (P0-09) [infra] UI shell hardening — resolution-independent scaling (letterbox 16:9), mouse-drag placement with snap and invalid-drop feedback, hotkeys (reroll, buy xp, sell, start), pause menu with abandon run, results screen with run summary; screen state machine fully unit-tested; manual checklist in PROGRESS.md. — acceptance: state-machine tests cover every transition; checklist ticked. — refs: infra
- [ ] (P0-10) [infra] Perf harness — `npm run bench` reports fights/sec and ticks/sec plus a host-independent budget (ticks per unit of a baseline micro-benchmark); numbers recorded in PROGRESS.md; slow-tier regression test at ±30% of the recorded budget. — acceptance: bench runs; budget recorded; test present in tests/slow. — refs: infra
- [ ] (P0-11) [infra] Fuzz — random legal + illegal command sequences: invariants hold (gold ≥ 0, board within bounds and cap, no duplicate uids, hp ≥ 0), illegal commands rejected with reasons and no state change. Fast: 200 sequences × 200 steps; slow: 20k sequences. — acceptance: both tests pass. — refs: infra
- [ ] (P0-12) [infra] Soak — 200 random-policy runs to completion with zero exceptions / NaN / Infinity; slowest run and mean run time reported. tests/slow. — acceptance: passes. — refs: infra
- [ ] (P0-13) [infra] Telemetry — every run writes a report JSON (seed, commands, per-round hashes, outcome, timings) to telemetry/ (gitignored) via the dev endpoint (dev) or a download button (prod); `tools/sweep.ts --telemetry <dir>` ingests human runs as extra seeds. — acceptance: a dev run produces a file; sweep ingests it. — refs: infra
